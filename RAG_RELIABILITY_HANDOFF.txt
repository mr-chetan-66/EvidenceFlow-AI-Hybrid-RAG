ROOT CAUSES VERIFIED
1. FastAPI startup restored BM25 with `collection.get(limit=100)`, so the hybrid keyword index covered only 100 rows of a potentially 12k+ Chroma collection. The sample first 100 local rows were 99 from AWS services explained.pdf and 1 from aws-overview.pdf. Startup now paginates the entire Chroma collection and restores documents, IDs, and metadata.
2. BM25 tokenized queries using whitespace only. Common question words such as "what" and "is" polluted rankings for questions like "what is AWS".
3. Hybrid scoring compared independently normalized BM25 and Chroma distance values as though the scales matched. In the observed local query, unrelated BM25-only results scored 0.86-1.00 while useful dense results scored 0.05-0.17. This caused keyword noise to outrank relevant vector results.
4. The query cache performed semantic matching and served different questions from cached answers. A local exact cache entry existed for "what is aws". The cache was versioned to 3.0 and now reuses exact questions only; older cache versions are discarded on load.
5. Empty retrieval still invoked the LLM and citation-disabled responses were marked supported with confidence 0.8. The agent now returns an explicit insufficient-evidence response at confidence 0 without an LLM call; citation verification disabled is represented as unknown, not supported.
6. The answer prompt omitted source/page labels even though metadata was available. It now includes source file and page with every evidence item.
7. `run_evaluation.py` previously re-embedded files and wrote into the configured vector store, making evaluation destructive. It now reads the existing vector collection only.
8. The AWS deploy workflow installed requirement.txt, which lacks psycopg2-binary. requirements_render.txt includes it. AWS workflow and Render manifest now install requirements_render.txt.
9. Streamlit backup startup had the same 100-row BM25 restore and silently truncated processing to 500 pages. evidenceflow_app.py now uses the shared persistent PDF path and full metadata-aware index.
10. Evaluation reported citation support as a failure when verification was disabled. It now reports verification coverage separately and support as N/A when no checks were performed.
